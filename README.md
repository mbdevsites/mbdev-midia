# mbdev-midia

Mídias e ferramentas das redes sociais da MBDev (@mbdevsites). Repositório público: a Metricool baixa as artes e vídeos daqui pelo link "raw".

- `semana-NN/`: artes (PNG 1080x1350), Reels (MP4 1080x1920) e `LEGENDAS.md` de cada semana.
- `ferramentas/`: scripts que geram as artes e os Reels. Veja `ferramentas/README.md`.

Link público de um arquivo: `https://raw.githubusercontent.com/mbdevsites/mbdev-midia/main/<caminho>`
